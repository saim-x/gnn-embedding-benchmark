# Security Policy

## Reporting a vulnerability

If you discover a security issue, report it through GitHub private vulnerability reporting (Security tab) instead of opening a public issue.

Include:

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation (if available)

## Scope

This project is a research scaffold and is not intended for production deployment. Treat all serialized dataset inputs (`.pt` files) as trusted local data only.
